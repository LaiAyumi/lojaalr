# Carrinho de Compras

Front-end de e-commerce com carrinho de compras funcional: adicionar/remover itens e cálculo de total em tempo real.

## ✨ Funcionalidades

- Listagem de produtos
- Carrinho com adição, remoção e atualização de quantidade
- Cálculo automático do total da compra
